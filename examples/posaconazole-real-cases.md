# 真实病例：泊沙康唑相关高血压与低钾

[返回病例目录](./README.md)

## 输入病例

> 成人使用泊沙康唑后出现高血压、低钾、代谢性碱中毒，肾素和醛固酮偏低。

## Skill 找到的相似病例

### 1. 68 岁女性，急性髓系白血病

| 项目 | 内容 |
|---|---|
| 相似度 | **高度相似**。药物暴露、高血压、低钾、代谢性碱中毒、低肾素和低醛固酮均与输入病例一致。 |
| 病例情况 | 泊沙康唑预防治疗期间出现血压升高和难治性低钾，血钾最低 2.6 mEq/L；碳酸氢根最高 39 mEq/L，静脉血 pH 7.52；醛固酮 2 ng/dL，肾素活性 0.05 ng/mL/h。 |
| 重要差异 | 患者为 68 岁女性，基础疾病为急性髓系白血病；输入病例未限定年龄、性别和基础疾病。 |
| 治疗 | 使用螺内酯，随后停用泊沙康唑。 |
| 结局 | 电解质恢复，停用泊沙康唑后未再复发。 |

### 2. 两例侵袭性真菌感染患者

| 项目 | 内容 |
|---|---|
| 相似度 | **高度相似**。两例均在泊沙康唑治疗后出现高血压、低钾、低肾素和低醛固酮。 |
| 病例情况 | 一例因球孢子菌病使用泊沙康唑，另一例为鼻脑型毛霉病。血液和尿液类固醇分析均支持盐皮质激素过多，但两人的生化机制不同。 |
| 重要差异 | 第一例以 11β-羟化酶抑制为主，第二例以 11β-HSD2 抑制更明显；说明相同临床表型不一定来自完全相同的机制。原文摘要未分别给出两例的年龄、性别及是否存在代谢性碱中毒。 |
| 治疗 | 第一例改用艾沙康唑；第二例降低泊沙康唑剂量。 |
| 结局 | 第一例的盐皮质激素过多表现消失，第二例在减量后改善。 |
| 来源 | Thompson et al., 2019；[PMID 31286100](https://pubmed.ncbi.nlm.nih.gov/31286100/)；[开放全文 PMC6608555](https://pmc.ncbi.nlm.nih.gov/articles/PMC6608555/)；[DOI 10.1210/js.2019-00189](https://doi.org/10.1210/js.2019-00189) |

## 结论

这组病例反复出现“泊沙康唑暴露后高血压、低钾以及肾素-醛固酮受抑制”的组合，支持药物相关表观盐皮质激素过多这一相似方向。不同患者可能以 11β-羟化酶抑制、11β-HSD2 抑制或两者共同作用为主；停药、减量、换药和螺内酯后的改善提供了有价值的时间关系，但不能直接证明另一位患者的因果关系或治疗选择。

病例相似只用于文献回顾和提出假设，不能确定当前患者的诊断、治疗方案或预后。
