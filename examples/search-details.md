# 案例检索详情

[返回中文首页](../README.md)

本页记录 README 中三个真实复杂病例的比较过程、相似维度和结果索引。公众号文章用于发现适合作为输入的公开病例，病例事实随后回到对应原始论文或开放全文核对；相似病例的治疗和结局也以原始文献为准。

## 比较阶段

| 阶段 | 处理内容 | 形成的结果 |
|---|---|---|
| 1. 输入核对 | 确认病例来自公开来源，去除姓名、机构内编号、精确日期等身份信息 | 可公开比较的完整临床病例 |
| 2. 病例指纹 | 提取年龄与性别、症状顺序、诱因或药物暴露、关键检查、重要阴性结果、治疗和结局 | 保留诊断转折的结构化病例特征 |
| 3. 相似维度 | 根据当前病例确定必须匹配和用于区分的维度，不使用所有疾病共用的固定清单 | 每个病例独立的比较框架 |
| 4. 病例发现 | 从表现、时间关系、诊断、鉴别方向和治疗反应寻找可能相关的病例论文 | 待核对病例集合 |
| 5. 原文核对 | 回到摘要或开放全文确认患者级事实，区分论文明确报告、未报告和不一致的信息 | 可追溯的病例事实 |
| 6. 相似性判断 | 逐维度比较相同点、重要差异和未知项，同时考虑证据是否足以支持判断 | 高度相似、较相似或部分相似 |
| 7. 结果呈现 | README 展示 TOP 3；其余已核对病例保留在各案例详情页 | 精简首页与完整证据索引 |

## 相似度分级

相似度是定性文献比较，不是诊断概率，也不是经过临床验证的百分比。

| 分级 | 判断方式 |
|---|---|
| 高度相似 | 核心表现、症状顺序或时间关系，以及关键客观检查大体一致；差异不会改变主要比较方向 |
| 较相似 | 主要临床模式一致，但缺少一项关键证据，或年龄、病因、严重程度、遗传背景和治疗路径存在重要差异 |
| 部分相似 | 共享部分重要表现或相同的诊断转折，但存在足以改变临床解释的关键差异 |

未在原文中出现的信息记为“未说明”，不会当作相同或不同。

## Case 1：泊沙康唑相关盐皮质激素过多

### 输入来源

- 公众号线索：ImmunoTHrombosis《检验案例｜抗真菌药泊沙康唑致假性醛固酮增多症》。
- 病例核对：[PMID 33305136](https://pubmed.ncbi.nlm.nih.gov/33305136/)、[开放全文 PMC7710826](https://pmc.ncbi.nlm.nih.gov/articles/PMC7710826/)。

### 相似维度

| 优先级 | 维度 | 输入病例 |
|---|---|---|
| 核心 | 药物时间关系 | 使用泊沙康唑后出现或加重异常 |
| 核心 | 临床表型 | 高血压、难治性低钾、代谢性碱中毒 |
| 核心 | 内分泌证据 | 肾素和醛固酮均受抑制 |
| 重要 | 肾脏证据 | 尿钾排泄增加，支持肾性失钾 |
| 重要 | 鉴别证据 | 肾上腺影像无肿瘤，尿游离皮质醇正常 |
| 补充 | 干预反应 | 盐皮质激素受体拮抗、停药、减量或换药后的变化 |

## Case 3：难治性癫痫路径中的 CPVT 与双重心动过速

### 输入来源

- 公众号线索：循环在线《心电病例：宽、窄 QRS 波心动过速导致儿童心肺骤停——最佳治疗策略是什么？》。
- 病例核对：[PMID 37869737](https://pubmed.ncbi.nlm.nih.gov/37869737/)、[开放全文 PMC10586193](https://pmc.ncbi.nlm.nih.gov/articles/PMC10586193/)。

### 相似维度

| 优先级 | 维度 | 输入病例 |
|---|---|---|
| 核心 | 发作表现 | 儿童期抽搐样发作，最终发生心肺骤停 |
| 核心 | 诊断延迟 | 以“难治性癫痫”治疗 5 年后才识别心律失常 |
| 核心 | 心律证据 | 异丙肾上腺素激发双向室速，并同时存在局灶性房性心动过速 |
| 重要 | 常规治疗反应 | 电复律、胺碘酮和维拉帕米只能短暂控制 |
| 重要 | 遗传结果 | CPVT 基因 panel 未发现阳性变异 |
| 补充 | 治疗与结局 | 纳多洛尔联合氟卡尼后的心律控制、心功能恢复和随访 |

## 证据边界

- 公众号搜索结果只是公开病例线索，不用于支撑相似病例的临床结论。
- 摘要能够支持的事实按摘要记录；只有实际查看开放全文时才使用全文细节。
- 同一篇文章中的多位患者会明确标为病例系列，不把论文数量当作患者数量。
- 输入病例的原始论文不再作为“相似病例”重复计入结果。
- 排名靠前只表示与当前输入的临床维度更接近，不代表来源质量更高或治疗更适合当前患者。

病例相似只用于文献回顾和提出假设，不能确定当前患者的诊断、治疗方案或预后。
