# 案例检索与比较详情

[返回中文首页](../README.md) · [查看真实病例索引](./README.md)

本页记录两组中国临床案例成果数据库输入的病例指纹、检索阶段、相似维度、分级依据和结果去向。用户提交的 3 个链接中前两条完全相同，因此患者级去重后只有 2 个输入病例；重复链接没有再次检索或计数。

## 处理阶段

| 阶段 | 处理内容 | 结果 |
|---|---|---|
| 1. 输入核对 | 读取公开病例，确认正式题名和病例库记录，删除姓名、机构内编号和精确日期 | 2 个可公开比较的唯一病例 |
| 2. 病例指纹 | 拆分年龄段、症状顺序、诱因、关键检查、病理、治疗及结局 | 保留诊断转折的病例特征 |
| 3. 查询变体 | 分别从高精度组合、表现、诊断与鉴别、同义词、病理或治疗方向检索 | 避免只依赖疾病名称 |
| 4. 来源检索 | 使用 PubMed、Europe PMC 和 OpenAlex 查找病例论文；中文病例库和公众号保留为独立来源类别 | 形成候选文献集合 |
| 5. 去重与初排 | 按 DOI、PMID、PMCID 和题名合并重复记录，再按病例特异维度排序 | 文献候选，不直接称为患者病例 |
| 6. 原文核验 | 回到摘要或开放全文确认患者、治疗、结局及是否重复报道 | 形成患者级病例比较 |
| 7. 关系扩展 | 对接近的种子论文检查相似文章、参考文献和引用论文 | 补充旧称、非典型病因和近似病例 |
| 8. 结果呈现 | 首页展示 TOP 3，详情页展示 5 个已核验病例 | 精简首页与可追溯详情并存 |

## 相似度评分

每个输入病例先确定“主要病例轴”：已确认诊断使用主要病种；诊断未定时使用明确声明的核心综合征或关键机制。候选必须先通过主要病例轴的患者级核验，才有资格进入相似病例列表。未通过者即使共享多个症状，也只能列为相关或鉴别病例，不能靠次要维度加权进入 TOP。通过准入后，再定义 4～7 个病例特异维度及权重，权重合计为 100。维度不使用所有疾病通用的固定模板：复杂性心悸强调症状与低血糖的时间关系、糖代谢、低钾机制和心脏证据；BADAS 强调肠道触发、皮肤关节组合、组织病理和基础肠病背景。

| 单维评分 | 含义 |
|---:|---|
| 5 | 关键表现、时间关系或客观证据近乎一致 |
| 4 | 强匹配，存在不改变主要比较方向的差异 |
| 3 | 中等匹配，同时存在一项重要差异 |
| 2 | 部分匹配，病因、病理或病程差异明显 |
| 1 | 只共享宽泛类别或单个弱特征 |
| 0 | 原文明确报告相反或不兼容的事实 |
| ? | 原文未说明，不能据此判断相同或不同 |

加权相似度的计算方式为：已评估维度的“权重 × 单维评分 ÷ 5”之和，再除以已评估维度权重之和并换算为 100 分，展示时四舍五入为整数。证据覆盖率等于已评估维度权重之和；未知维度不按 0 分处理，但会降低覆盖率。

| 加权相似度 | 展示分级 |
|---:|---|
| 80～100 | 高度相似 |
| 60～79 | 较相似 |
| 40～59 | 部分相似 |
| 0～39 | 低相似 |

总分用于排序和解释，不是经过临床验证的概率。若候选病例在病原、病理、关键阴性结果或症状顺序上存在决定性冲突，即使其他维度分数较高，也必须单独显示冲突，不能由总分覆盖。来源质量、检索置信度和临床相似度分别报告，不混成一个分数。

## Case 1：多病因复杂性心悸

### 病例指纹

| 类别 | 去标识化特征 |
|---|---|
| 人群与主诉 | 中年男性，反复心悸，后期伴持续胸闷 |
| 症状顺序 | 早期短暂、定时样发作且进食缓解，后期发作延长 |
| 代谢证据 | 发作期血糖 2.7 mmol/L、Whipple 三联征、OGTT 后高胰岛素反应和糖耐量异常 |
| 电解质证据 | 低钾并有尿钾排泄增加，考虑长期饮酒相关肾性失钾 |
| 心脏证据 | 左前降支浅表型心肌桥；动态心电图无器质性心律失常 |
| 干预与结局 | 代谢、补钾、心血管及戒酒等多因素处理后，6 个月症状和客观指标改善 |

### 查询方向

- 心悸与记录到的低血糖、进食后缓解。
- 反应性或餐时相关低血糖与高胰岛素反应。
- 心悸、低血糖和低钾同时出现。
- 低血糖与心脏结构或心律异常并存。
- 多病因共同解释心悸的病例路径。

### 检索与核验结果

| 阶段 | 数量 | 含义 |
|---|---:|---|
| 查询与来源组合 | 12 / 12 成功 | 5 类英文查询覆盖 PubMed、Europe PMC 和 OpenAlex |
| 实际返回记录 | 136 | 不同来源和查询间存在重复 |
| 去重后候选文献 | 118 | 是论文或索引记录，不是 118 位患者 |
| 进入本次患者级详查 | 5 | 均确认描述真实患者 |
| 首页展示 | 3 | 按症状时间关系、多病因路径和证据完整度选择 |

自动初排的 118 篇候选中，没有任何一篇摘要同时出现心肌桥、低血糖和低钾。进一步核验和关系扩展后，结果仍分布在“低血糖相关心悸”“低血糖与低钾共存”“低血糖与心脏异常共存”三个分支。因此该病例的最佳结果止于“较相似”，没有为了填满结果而标出高度相似病例。

## Case 2：感染性结肠炎继发 BADAS

### 病例指纹

| 类别 | 去标识化特征 |
|---|---|
| 人群与主诉 | 老年女性，急性肠道症状后出现发热、疼痛性四肢皮疹和多关节痛 |
| 肠道证据 | 产毒性艰难梭菌阳性；结直肠重度活动性炎症伴糜烂 |
| 皮损形态 | 上肢丘疹脓疱，下肢斑片和皮下结节，均有压痛 |
| 组织病理 | 上肢白细胞碎裂性血管炎，下肢间隔性脂膜炎 |
| 背景排除 | 无既往明确 IBD，无肠道旁路手术 |
| 干预与结局 | 糖皮质激素、沙利度胺、抗炎和肠道治疗后完全消退，2 个月无复发 |

### 查询方向

- BADAS 与艰难梭菌或感染性结肠炎。
- 脓疱、皮下结节、关节炎和腹泻的表现组合。
- BADAS、Sweet 综合征、结节性红斑和坏疽性脓皮病的鉴别路径。
- 旧称 bowel bypass syndrome 及没有肠道旁路的病例。
- 白细胞碎裂性血管炎、脂膜炎、糖皮质激素或沙利度胺。

### 检索与核验结果

| 阶段 | 数量 | 含义 |
|---|---:|---|
| 查询与来源组合 | 12 / 12 成功 | 5 类英文查询覆盖 PubMed、Europe PMC 和 OpenAlex |
| 实际返回记录 | 184 | 不同来源和查询间存在重复 |
| 去重后候选文献 | 144 | 是论文或索引记录，不是 144 位患者 |
| 进入本次患者级详查 | 5 | 5 位患者；含 1 例诊断重叠的近似病例 |
| 首页展示 | 3 | 优先感染或细菌触发、皮肤关节组合及完整随访 |

这一组能稳定召回 BADAS 及其旧称，并通过关系扩展找到阑尾炎、细菌过度生长和憩室炎等非经典肠道背景。未检出独立的艰难梭菌相关 BADAS 报告，也没有其他病例同时呈现血管炎和脂膜炎两种区域病理，因此输入病例在病原和病理组合上仍然独特。

## 来源与证据范围

| 来源类别 | 本次用途 | 边界 |
|---|---|---|
| 中国临床案例成果数据库 | 核对输入病例的正式记录和病例摘要 | 输入病例不作为自己的相似结果重复计入 |
| 用户提供的公众号原文 | 定位公开输入 | 不用公众号替代相似病例的原始论文证据 |
| PubMed | 病例发现、标识符和摘要核验 | 摘要未报告的治疗或结局记为未说明 |
| Europe PMC | 摘要、开放全文和 PMCID 核验 | 有全文链接不等于已经查看；本页只在实际查看后标为全文证据 |
| OpenAlex | 扩展发现、引用和相关论文线索 | 临床事实回到 PubMed、Europe PMC 或论文原文核对 |
| SinoMed、CNKI、万方、维普 | 中文扩展路径 | 访问和订阅条件不同，本次未把不可完整核验的记录纳入 TOP 结果 |

## 已知盲区

- 中国数据库的机构订阅范围可能影响可见记录，未访问到的记录不能解释为不存在。
- 公众号和社交平台没有可证明穷尽性的公共检索能力。
- 病例论文可能使用旧病名、只在正文出现关键表现，或尚未被数据库收录。
- 同一患者可能在会议摘要、病例库和期刊中重复出现；只有患者级信息足以排重时才合并。
- 病例相似性用于提出检索和鉴别假设，不能建立诊断、因果关系、治疗适用性或预后。
