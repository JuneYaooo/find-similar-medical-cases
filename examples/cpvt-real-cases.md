# 真实病例：运动诱发晕厥、抽搐样发作与双向室速

[返回病例目录](./README.md)

## 输入病例

> 儿童、青少年或年轻成人在运动或情绪激动时发生晕厥、抽搐样发作或心脏骤停；静息检查可能正常，运动试验出现双向或多形性室性心动过速。

## Skill 找到的相似病例

### 1. 9 岁男孩，运动后抽搐

| 项目 | 内容 |
|---|---|
| 相似度 | **高度相似**。运动诱发抽搐、运动试验双向室速和致病性 RYR2 变异完整匹配输入病例。 |
| 病例情况 | 9 岁时因运动后抽搐就诊，跑台试验记录到双向室速，遗传检查发现 RYR2 致病变异。其后病情反复，并出现室颤和 ICD 放电。 |
| 重要差异 | 该病例为对多线治疗仍反复发作的难治型；输入病例没有说明遗传结果和既往治疗。 |
| 治疗 | 先后使用纳多洛尔、氟卡尼和胺碘酮，接受左侧心脏交感神经切除及 ICD 植入；仍控制不佳后追加右侧心脏交感神经切除。 |
| 结局 | 双侧交感神经切除后室速消失，随访无症状，复查运动试验未见运动诱发室早或室速。 |
| 来源 | [PMID 39735866](https://pubmed.ncbi.nlm.nih.gov/39735866/)；[开放全文 PMC11671521](https://pmc.ncbi.nlm.nih.gov/articles/PMC11671521/)；[DOI 10.3389/fcvm.2024.1477359](https://doi.org/10.3389/fcvm.2024.1477359) |

### 2. 21 岁女性，心脏骤停

| 项目 | 内容 |
|---|---|
| 相似度 | **较相似**。年轻患者、心脏骤停和明确双向室速一致，但摘要未说明运动或情绪诱因，遗传结果也是意义未明变异。 |
| 病例情况 | 21 岁女性因心脏骤停送医，心电图记录到双向室速；全基因组检查发现 CALM2 杂合意义未明变异。 |
| 重要差异 | 遗传背景不是典型的 RYR2 或 CASQ2 致病变异，且发作诱因和静息检查情况未在摘要中说明。 |
| 治疗 | 使用普萘洛尔并植入皮下 ICD。 |
| 结局 | 开始普萘洛尔后未再出现室性心律失常；摘要未提供更长期随访。 |
| 来源 | [PMID 39104518](https://pubmed.ncbi.nlm.nih.gov/39104518/)；[开放全文 PMC11299022](https://pmc.ncbi.nlm.nih.gov/articles/PMC11299022/)；[DOI 10.1093/ehjcr/ytae340](https://doi.org/10.1093/ehjcr/ytae340) |

### 3. 6 岁男孩，被当作癫痫样发作

| 项目 | 内容 |
|---|---|
| 相似度 | **高度相似**。运动诱发抽搐样发作、正常静息心电图和 Holter、运动试验双向室速均与输入病例高度吻合。 |
| 病例情况 | 反复出现运动诱发的癫痫样发作，神经影像正常；运动试验暴露双向室速，遗传检查发现 CASQ2 纯合变异，符合 CPVT2。 |
| 重要差异 | 该病例的遗传类型为 CPVT2；输入病例没有指定基因类型。 |
| 治疗 | 普萘洛尔联合氟卡尼，未植入 ICD。 |
| 结局 | 药物治疗成功控制病情；摘要未提供具体随访时长。 |
| 来源 | [PMID 42435031](https://pubmed.ncbi.nlm.nih.gov/42435031/)；[DOI 10.1016/j.jaccas.2026.109233](https://doi.org/10.1016/j.jaccas.2026.109233) |

### 4. 4、5、10 岁儿童心脏骤停病例系列

| 项目 | 内容 |
|---|---|
| 相似度 | **高度相似**。三例均由轻活动、水中活动或奔跑触发心脏骤停，并记录到多灶室性异位、双向或多形性室速，且均有新发 RYR2 变异。 |
| 病例情况 | 三位此前健康的儿童发生心脏骤停。两例在重复使用肾上腺素期间心律失常加重；第三例较早识别 CPVT。 |
| 重要差异 | 这是心肺复苏场景中的重症病例系列，重点讨论急救期间儿茶酚胺刺激与心律失常的关系，而输入病例覆盖的严重程度更广。 |
| 治疗 | 三例均接受旁观者心肺复苏和除颤；两例后续使用 ECMO。识别 CPVT 后采用静脉阿片类药物、全身麻醉并避免肾上腺素，其中一例使用氟卡尼转复。 |
| 结局 | 三例均恢复自主循环；较早识别并避免肾上腺素的第三例病程明显更好且未使用 ECMO。摘要未提供长期随访。 |

### 5. 4 岁男孩，难治性室性心律失常与心源性休克

| 项目 | 内容 |
|---|---|
| 相似度 | **较相似**。结构正常心脏和双向室速一致，但摘要没有说明最初是否由运动或情绪触发，也未提供遗传结果。 |
| 病例情况 | CPVT 引起的双向室速和难治性室性心律失常持续进展，最终发生心源性休克，常规药物和机械通气支持不足以稳定循环。 |
| 重要差异 | 病情严重到需要 ECMO；输入病例没有限定是否出现心源性休克。 |
| 治疗 | 在原有治疗基础上启动中心 ECMO 支持。 |
| 结局 | ECMO 第 10 天成功撤离，出院时状况良好，出院后随访结局良好。 |
| 来源 | [PMID 39773414](https://pubmed.ncbi.nlm.nih.gov/39773414/)；[开放全文 PMC11705711](https://pmc.ncbi.nlm.nih.gov/articles/PMC11705711/)；[DOI 10.1186/s12887-024-05357-y](https://doi.org/10.1186/s12887-024-05357-y) |

### 6. 17 岁男性，情绪事件中倒地

| 项目 | 内容 |
|---|---|
| 相似度 | **较相似**。情绪诱发倒地和心脏骤停、无结构性心脏病以及遗传学确诊均一致，但摘要没有报告运动试验或双向室速。 |
| 病例情况 | 在一次情绪事件中倒地并发生心脏骤停；既往有胸痛和心悸，存在猝死家族史，复苏后心电图没有持续异常，遗传检查最终确认 CPVT。 |
| 重要差异 | 关键线索来自情绪诱因、家族史和遗传检查，而不是运动试验记录到的双向或多形性室速。 |
| 治疗 | 开始使用 β 受体阻滞剂，并植入皮下 ICD。 |
| 结局 | 原文摘要未说明长期随访结局。 |
| 来源 | [PMID 36337791](https://pubmed.ncbi.nlm.nih.gov/36337791/)；[开放全文 PMC9626406](https://pmc.ncbi.nlm.nih.gov/articles/PMC9626406/)；[DOI 10.7759/cureus.29844](https://doi.org/10.7759/cureus.29844) |

## 结论

最接近输入病例的共同模式是“运动或情绪刺激后晕厥、抽搐样发作或心脏骤停，而静息检查可能没有异常，运动试验或发作期心电图才显示双向或多形性室速”。真实病例涉及 RYR2、CASQ2 和 CALM2 等不同遗传背景，严重程度也从药物可控到需要 ICD、交感神经切除或 ECMO。相似临床表现不能直接推出相同遗传原因、严重程度或治疗路径。

病例相似只用于文献回顾和提出假设，不能确定当前患者的诊断、治疗方案或预后。
