# 真实病例：急性精神症状、癫痫与卵巢畸胎瘤

[返回病例目录](./README.md)

## 输入病例

> 青年女性急性出现精神或行为异常，随后发生癫痫、意识改变或异常运动，影像发现卵巢畸胎瘤。

## Skill 找到的相似病例

### 1. 21 岁女性，左侧卵巢畸胎瘤

| 项目 | 内容 |
|---|---|
| 相似度 | **高度相似**。青年女性、急性精神行为异常、癫痫、脑脊液抗体阳性和卵巢畸胎瘤均与输入病例一致。 |
| 病例情况 | 出现急性行为异常、幻觉和癫痫，最初被诊断为原发精神疾病；脑脊液抗 NMDAR 抗体阳性，盆腔 MRI 发现左侧卵巢畸胎瘤。 |
| 重要差异 | 脑 MRI 还显示左颞叶高信号；输入病例未提供抗体和脑 MRI 结果。 |
| 治疗 | 初始免疫治疗仅部分改善，随后切除畸胎瘤并继续使用糖皮质激素。 |
| 结局 | 神经和精神症状完全恢复；1 个月随访时症状完全消失、功能状态正常。 |
| 来源 | [PMID 42078602](https://pubmed.ncbi.nlm.nih.gov/42078602/)；[DOI 10.1097/MS9.0000000000004441](https://doi.org/10.1097/MS9.0000000000004441) |

### 2. 27 岁女性，首发精神病样表现

| 项目 | 内容 |
|---|---|
| 相似度 | **较相似**。急性精神和认知症状、血清及脑脊液抗体阳性、卵巢畸胎瘤均一致，但摘要没有报告癫痫或异常运动。 |
| 病例情况 | 既往健康，15 天内出现精神、认知和躯体症状，先收入早期精神病干预病房；精神症状缓解后仍有明显记忆缺陷，进一步检查发现血清和脑脊液抗体阳性及右侧卵巢畸胎瘤。 |
| 重要差异 | 该病例以首发精神病和持续认知缺陷为主，缺少输入病例中的癫痫、意识改变或异常运动证据。 |
| 治疗 | 腹腔镜切除肿瘤；静脉注射免疫球蛋白和甲泼尼龙 5 天。 |

### 3. 21 岁女性，严重运动障碍与自主神经症状

| 结局 | 5 个月后恢复；摘要未提供手术后的长期神经功能随访。 |

## 结论

最接近输入病例的论文共同呈现“青年女性急性精神症状，随后出现癫痫、意识或记忆障碍、异常运动，同时存在抗 NMDAR 抗体和卵巢畸胎瘤”的模式。肿瘤切除与免疫治疗后多有改善，但恢复可以从 1 个月到数月不等，病例系列中也出现精神症状复发。没有畸胎瘤的病例仍可共享神经精神表现，却应因关键病因线索不同而降低相似度。

病例相似只用于文献回顾和提出假设，不能确定当前患者的诊断、治疗方案或预后。
