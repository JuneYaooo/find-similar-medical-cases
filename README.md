# Find Similar Medical Cases

[English](./README.en.md) · [真实病例详情](./examples/)

一个面向医学研究人员和临床工作者的中英文相似病例检索 Skill。输入去标识化的临床病例后，它会从医学文献中寻找表现相近的真实病例，并整理病例情况、相同点、重要差异、治疗、结局和原始来源。

这里展示的案例均来自可核验的论文，不使用模拟患者。相似度用于帮助阅读和比较，不代表诊断概率。

## 使用方式

将病例中的年龄范围、症状顺序、关键检查、药物或暴露、治疗反应整理后提交给 Skill。不要提供姓名、联系方式、身份证件、病历号、精确地址或带有身份信息的检查资料。

## 真实病例展示

![三组真实复杂病例](./assets/real-case-overview.svg)

| 方向 | 输入的真实病例 | 相似病例总结 | 详情 |
|---|---|---|---|
| 药物不良反应 / 内分泌 | 成人使用泊沙康唑后出现高血压、低钾、代谢性碱中毒、低肾素和低醛固酮 | 多个年龄和基础疾病不同的病例重复出现表观盐皮质激素过多表型；停药、减量、换药或螺内酯治疗后可改善，但具体机制和恢复过程并不完全一致 | [泊沙康唑相关病例](./examples/posaconazole-real-cases.md) |
| 神经免疫 / 妇科 | 青年女性急性出现精神或行为异常，随后发生癫痫、意识改变或异常运动，并发现卵巢畸胎瘤 | 高度相似病例常有血清或脑脊液抗 NMDAR 抗体阳性；肿瘤切除联合免疫治疗后多数改善，但恢复速度和复发情况不同 | [抗 NMDAR 脑炎相关病例](./examples/anti-nmdar-real-cases.md) |
| 遗传性心律失常 | 儿童或年轻人在运动、情绪激动时晕厥、抽搐样发作或心脏骤停，静息检查可能正常，运动试验出现双向或多形性室速 | 真实病例显示静息心电图正常不能排除 CPVT；运动试验、发作诱因和遗传结果是关键线索，治疗从药物到 ICD、交感神经切除或 ECMO 不等 | [CPVT 相关病例](./examples/cpvt-real-cases.md) |

## 病例结论

- **泊沙康唑病例：** 高血压与低钾同时出现，且肾素、醛固酮被抑制时，真实病例反复指向药物相关的表观盐皮质激素过多。停药后消失、低剂量重启后不复发等时间关系增强了关联，但不能单凭相似病例证明个体因果。
- **抗 NMDAR 脑炎病例：** 青年女性的新发精神症状若很快合并癫痫、记忆或意识障碍、异常运动，应保留自身免疫性脑炎方向。卵巢畸胎瘤和脑脊液抗体是区分高度相似病例的重要证据。
- **CPVT 病例：** 运动或情绪诱发的抽搐样发作不能只按癫痫解释。静息检查可能没有异常，运动试验中的双向或多形性室速以及家族史、遗传结果更有区分力。
- **共同结论：** 症状发生顺序、诱因、药物时间关系和客观检查，比共享一个疾病名称更能判断病例是否真正相似；治疗和结局仍需逐例比较。

## 相似度怎么理解

- **高度相似：** 核心表现、时间关系和关键客观证据基本一致。
- **较相似：** 主要临床模式一致，但缺少部分关键检查，或年龄、病因、严重程度和治疗路径不同。
- **部分相似：** 共享重要表现或诊断转折，但存在会改变临床判断的关键差异。

原文没有提供的事实会明确标为“原文摘要未说明”，不会根据常识补全。

## 来源与边界

每个展示病例都附有 PMID、DOI 或开放全文链接，便于回到原始论文核对。这个项目适合病例回顾、病例讨论准备和研究探索；病例相似不能确定当前患者的诊断、因果关系、治疗适用性或预后，也不能代替正式系统综述和临床决策。
