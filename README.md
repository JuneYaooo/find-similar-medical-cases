# Find Similar Medical Cases

[English](./README.en.md) · [真实病例详情](./examples/)

一个面向医学研究人员和临床工作者的中英文相似病例检索 Skill。它从去标识化的临床表现出发，检索真实文献和病例线索，逐篇核对相同点、差异、证据范围与来源限制。

这里展示的不是模拟病例，也不会把数据库命中数直接写成患者数。每个病例结论都尽量回到 PMID、DOI、开放全文或可核验的原始来源。

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](./LICENSE)

## 怎么使用

在 Codex 中安装这个 Skill 后，直接描述已经去除身份信息的病例即可。例如：

> 帮我找相似病例：青年女性，急性出现精神症状，随后癫痫和异常运动，影像发现卵巢畸胎瘤。请列出真实病例、相同点、差异和实际查过的来源。

年龄范围、症状顺序、关键检查、用药或暴露、治疗反应，比完整病历更适合检索。不要提供姓名、联系方式、身份证件、病历号、精确地址或带身份信息的检查资料。

以下三组均在 2026 年 8 月 23 日实时查询 PubMed、Europe PMC 和 OpenAlex，并对前排结果回到摘要或开放全文核对。公众号公开搜索只用于发现中文复杂病例线索，临床结论仍以原始论文为依据。

## 这几组案例说明了什么

- **可以从表现出发，而不是先押一个诊断。** 精神症状、抽搐、晕厥、低钾等表现都可能跨越多个专科，先按临床指纹检索更容易保留鉴别方向。
- **真实病例中最有价值的是时间关系和客观证据。** 药物暴露后的变化、运动诱发心律失常、脑脊液抗体和肿瘤影像，比只共享一个疾病名称更能决定病例是否相似。
- **初始误诊本身也是检索线索。** 抗 NMDAR 脑炎常先进入精神科路径，CPVT 的抽搐样晕厥可被当作癫痫；检索会保留这些诊断转折。
- **公众号适合发现线索，不适合单独支撑结论。** 公开检索确实找到了中文病例文章，但会继续追溯其对应论文、病例库或医院来源。
- **候选文献不是患者数。** 一篇文章可能包含多位患者，同一患者也可能被多篇论文或转载重复描述。

## 它会做什么

- 把病例整理成去标识化的“病例指纹”，区分观察事实与怀疑诊断。
- 从高精度、表现优先、鉴别诊断、宽泛同义词等多个方向检索。
- 覆盖 PubMed、Europe PMC、OpenAlex 以及可访问的中文病例与文献入口。
- 沿接近的论文继续查看相似文章、参考文献和后续引用。
- 使用 DOI、PMID、PMCID、题名、年份和作者信息合并重复文献。
- 逐项记录相同、不同和未知，并区分题名、摘要、全文和二手线索。
- 报告哪些来源实际查过、哪些失败或受限，以及检索为何停止。

## 查询逻辑

一句话概括：**先从多个方向尽量找全，再逐条核对和比较。**

![相似病例查询逻辑](./assets/search-logic.svg)

相似度只用于安排阅读顺序，不是诊断概率。病例相似性、来源质量和检索可信度始终分开判断；原文没有提供的事实会标为“未知”，不会根据常识补全。

## 结果形式

![相似病例检索记录示意](./assets/report-preview.svg)

每次检索会形成总体报告、完整检索账本和候选文献资料页。最终结果保留原文题名、年份、稳定标识符、来源链接、证据范围、相同点、重要差异、未知事实和排除理由。

## 能查到哪里

英文医学文献以 PubMed 和 Europe PMC 为主，OpenAlex 用于扩大候选范围和查找引用关系。中文方向会按需要覆盖中国临床案例成果数据库、SinoMed、中国知网、万方、维普、中华医学期刊网以及专业公众号线索。

需要登录、机构订阅、验证码或付费服务的来源会明确标记为受限，不会被写成“零结果”，也不会绕过访问控制。

## 使用边界

这个项目适合病例回顾、病例讨论准备、研究选题探索和相似病例证据整理。病例相似只能用于文献回顾和提出假设，不能确定当前患者的诊断、因果关系、治疗适用性或预后，也不能代替正式系统综述。
